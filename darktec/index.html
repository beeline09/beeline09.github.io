    Скачать / собрать

    Скачать UF2 ZIP для BLE-OTA

    UF2 — копирование на DFU-диск с компьютера. ZIP для BLE-OTA — для обновления, например, через мобильное устройство.

    Как прошить (DFU)

    1. Подключите Darktec по USB.
    2. Дважды быстро нажмите RESET — появится USB-диск DFU.
    3. Перетащите скачанный .uf2 на этот диск.
    4. Плата перезагрузится; копирование может «оборваться» — это нормально.

    При нажатии на кнопку «Только DFU» произойдёт прошивка методом копирования файла обновления на диск, который появляется при переходе в режим DFU.

    Режим DFU включается двойным нажатием кнопки RESET.

    Если у вас старый бутлоадер (версия меньше 0.6.1), обновите его, предварительно переведя устройство в режим DFU.

    Нажатие кнопки «Прошить» прошивает устройство через Serial-интерфейс (не DFU). Для этого необходимо будет выбрать Serial интерфейс вашего подключённого модуля.

    Как собрать прошивку

    Готового файла для ваших настроек (имя и/или радио) ещё нет. Его нужно один раз собрать через GitHub (это бесплатно, но без вашего подтверждения сайт сам сборку запустить не может — такое ограничение).

    1. Сейчас откроется новая вкладка GitHub. Если попросит — войдите в аккаунт.
    2. На странице ничего не меняйте в тексте.
    3. Внизу нажмите зелёную кнопку «Create» или «Submit new issue».
    4. После этого вкладку GitHub можно закрыть и вернуться сюда.
    5. На этой странице подождите около 5 минут — когда файл появится, кнопка «Скачать UF2» станет активной. Только тогда можно прошивать.

    Если сразу нажать «Скачать» или «Прошить» — ничего не получится: файла ещё нет.
