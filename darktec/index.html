Как прошить (DFU)

  1. Подключите Darktec по USB.
  2. Дважды быстро нажмите кнопку Reset — появится USB-диск (часто DARKTEC / NRF52BOOT).
  3. Перетащите скачанный .uf2 на этот диск.
  4. Плата перезагрузится; копирование может «оборваться» — это нормально для UF2.

Нужна другая версия или zip-набор — смотрите GitHub Releases.
