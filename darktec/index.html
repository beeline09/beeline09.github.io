USB-инструменты

Нужен Chrome / Edge и плата в режиме приложения (не DFU), USB serial 115200. Работает с repeater / room server (и CLI, где есть). Не зависит от матрицы прошивок — только Web Serial. После прошивки переподключите плату в app-режиме.

Как прошить (DFU)

  1. Подключите Darktec по USB.
  2. Дважды быстро нажмите RESET — появится USB-диск DFU.
  3. Перетащите скачанный .uf2 на этот диск.
  4. Плата перезагрузится; копирование может «оборваться» — это нормально.

Прошить через USB Serial (как meshcore.io)

Chrome / Edge + Web Serial: плата сама уходит в DFU (1200 baud), затем заливается OTA .zip по serial — без ручного копирования на диск. Обычно достаточно выбрать обычный COM один раз — DFU-порт подхватывается сам; второй раз выбрать порт нужно только если автоопределение не сработало. Для крупных прошивок на Darktec/ProMicro/nice!nano рекомендуется Adafruit UF2 ≥ 0.6.1 (лучше OTAFIX 0.9.2) — проверьте и обновите отдельно кнопкой «Обновить bootloader»; «Прошить» бутлоадер не проверяет и не спрашивает. Обычная прошивка («Прошить» / «Только DFU») уводит плату в Serial DFU через 1200 baud — USB-диск при этом не ожидается. «Обновить bootloader» пишет OTAFIX на USB-диск UF2: подключите USB → дважды быстро RESET → появится том (часто NICE_NANO / MADMIXIN / FTHRS…) → «Выбрать диск UF2» (INFO_UF2.TXT → запись OTAFIX). COM-порт для обновления бутлоадера не нужен.

После «Прошить» плата перезагрузится: для Console / «Настройка repeater» снова выберите COM в режиме приложения (не DFU).
